# Essential Shield — Website

A complete redesign of essentialshield.com built as a fast, responsive, static
site in vanilla HTML, CSS and JavaScript. No build step or dependencies are
required to deploy — `index.html` is the entry point.

**Essential Shield** — 100% natural mould remediation, restoration and cleaning,
17 years servicing the Queensland community.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Home — hero with before/after slider, services, process, reviews, products, FAQs, contact |
| `services.html` | Mould remediation, water damage restoration, pressure washing, bond & end of lease cleans |
| `products.html` | Mr Mould & Naturamax range, stockists, shipping & payment |
| `faq.html` | Full FAQ list with FAQPage structured data |
| `contact.html` | Contact details and message form |
| `quote.html` | Quote request form |
| `policies.html` | Terms, privacy, shipping & payment, returns |

## Assets

- `assets/css/styles.css` — design system (tokens, layout, components, responsive rules)
- `assets/js/main.js` — mobile nav, scroll reveals, before/after comparison slider, form handling
- `assets/favicon.svg` — favicon

## Forms

Every form (contact, quote, quick quote, newsletter) posts to the LeadrVision
endpoint:

```
https://vision.leadrai.com/api/forms/4dfea5213f838b89b8fd940221481367
```

Each form includes a `_form` name, a `_page` field stamped with
`window.location.href` on load, and a hidden `_gotcha` honeypot. Forms submit via
`fetch()` with an inline confirmation, and fall back to a plain HTML POST
(returning to the page with `?submitted=1`) when JavaScript is unavailable.

## Regenerating pages

`index.html` is hand-maintained. The remaining pages share a header/footer shell
and are generated by:

```bash
python3 tools/build_pages.py
```
